# 優化待辦事項

本清單由[介面與功能優化建議](IMPROVEMENT_RECOMMENDATIONS.md)轉換而來。每個項目使用不重複且固定的 `SDS-NNN` 編號；完成項目時保留原編號，不重新排序或重複使用。

狀態標記：`[ ]` 未完成、`[x]` 已完成。優先級由高至低為 P0、P1、P2。

## P0：資料與流程可靠性

- [ ] **SDS-001 建立文件庫與草稿管理**
  - 範圍：列出、建立、開啟、重新命名與刪除文件，顯示頁數及更新時間，清理空白草稿。
  - 驗收：建立新文件後仍可重新開啟舊文件；刪除文件會移除資料庫記錄與私有頁面檔案；程序重啟後清單一致。

- [ ] **SDS-002 加入刪除頁面復原機制**
  - 範圍：刪除後顯示含頁碼的 Snackbar 及「復原」，延遲實際刪檔。
  - 驗收：Snackbar 有效期間可恢復相同頁面與順序；逾時後資料庫及檔案均刪除；TalkBack 會讀出受影響頁碼。

- [x] **SDS-003 強制整份文件最多 50 頁**
  - 範圍：依現有頁數限制下一次掃描，匯入時再次驗證並顯示剩餘頁數。
  - 驗收：任何掃描或匯入路徑都無法使文件超過 50 頁；達上限時掃描按鈕停用並說明原因。

- [ ] **SDS-004 統一長時間作業狀態與進度**
  - 範圍：涵蓋準備掃描、匯入及匯出，停用排序、刪除、新文件與重複啟動等衝突操作。
  - 驗收：同時間只能執行一項文件作業；多頁處理顯示目前頁數與總頁數；旋轉畫面不會重複啟動作業。

- [ ] **SDS-005 支援多張 JPEG 正確分享**
  - 範圍：匯出結果保留所有圖片 URI，使用 Android 多檔分享，並重新定義開啟行為。
  - 驗收：匯出 N 頁後分享 Intent 含 N 個 URI 且授予讀取權限；介面不再暗示能以單檔開啟全部圖片。

- [ ] **SDS-006 加入匯入與匯出失敗清理**
  - 範圍：處理批次中途失敗、孤兒私有檔案、MediaStore 部分輸出及空白草稿。
  - 驗收：模擬任一頁失敗後不留下不可見檔案；若允許部分成功，訊息會列出成功與失敗數量；清理流程有自動化測試。

## P1：核心使用體驗

- [ ] **SDS-007 建立可復原的錯誤模型與首次使用說明**
  - 範圍：區分取消、Play 服務不可用、元件下載、讀取失敗、空間不足與初始化失敗，提供重試或說明入口。
  - 驗收：介面不直接顯示例外訊息；初始化失敗不會永久停在載入畫面；掃描取消不顯示錯誤。

- [ ] **SDS-008 支援文件重新命名**
  - 範圍：從文件庫及文件畫面修改名稱，驗證空白、保留字元與重名情況。
  - 驗收：名稱在重啟後保留；後續預設匯出檔名使用安全化後的新名稱。

- [ ] **SDS-009 支援自選輸出檔名與位置**
  - 範圍：保留一鍵預設匯出，另以 Storage Access Framework 提供自選目的地。
  - 驗收：使用者可取消選擇而不產生檔案；成功後可開啟或分享正確 URI；不要求廣泛儲存權限。

- [ ] **SDS-010 新增完整頁面預覽**
  - 範圍：點選縮圖開啟大圖，支援縮放、頁面切換、目前頁碼及返回原順序位置。
  - 驗收：50 頁文件可流暢瀏覽且不載入全部原尺寸 Bitmap；旋轉及程序重建後保留目前頁面。

- [ ] **SDS-011 加入旋轉、替換與重新裁切流程**
  - 範圍：先提供旋轉及替換，再評估重新裁切、濾鏡與亮度；保留復原能力。
  - 驗收：編輯後縮圖及 JPEG/PDF 輸出一致；取消編輯不改變原頁；不因反覆儲存造成明顯品質下降。

- [ ] **SDS-012 加入拖曳排序與無障礙替代操作**
  - 範圍：拖曳把手、自動捲動、頁碼回饋，並保留移至前一頁／後一頁動作。
  - 驗收：50 頁文件可將任一頁拖至目標位置；重新啟動後順序一致；TalkBack 與鍵盤不依賴拖曳也能排序。

- [ ] **SDS-013 新增 PDF 與圖片輸出選項**
  - 範圍：紙張尺寸、方向、邊界及品質，後續可獨立評估 OCR 與可搜尋 PDF。
  - 驗收：預設值維持目前快速匯出；設定結果與預覽或說明一致；各組合均能被常見檢視器開啟。

- [ ] **SDS-014 建立自適應且可捲動的主畫面**
  - 範圍：支援小螢幕、橫向、分割畫面、大字體與平板配置。
  - 驗收：200% 字體及常見窄寬度下主要操作不被裁切或重疊；橫向可完成掃描到匯出的完整流程。

- [ ] **SDS-015 重整頂端操作與 App 導覽**
  - 範圍：移除「移至背景」，建立文件庫、文件編輯及設定的標準導覽，低頻操作移至 overflow menu。
  - 驗收：系統返回操作符合使用者預期；文件長名稱不會擠壓主要動作；深層頁面可恢復狀態。

- [ ] **SDS-016 保存並顯示匯出紀錄**
  - 範圍：記錄檔名、格式、頁數、目的地、時間與 URI 可用狀態。
  - 驗收：程序重啟後仍可查看紀錄；URI 失效時提供清楚訊息及移除紀錄動作；最近結果不因頁面 Flow 更新而消失。

## P2：可及性、在地化與資訊

- [ ] **SDS-017 完善頁面清單無障礙語意**
  - 範圍：集合位置、頁碼上下文、操作結果公告、焦點順序、觸控目標與鍵盤操作。
  - 驗收：TalkBack 可辨識每頁位置與可用動作；排序、刪除及復原後有狀態公告；互動目標符合 Material 最小尺寸。

- [ ] **SDS-018 完善設定頁及色彩選擇器無障礙**
  - 範圍：滑桿標籤與值描述、選取狀態、標題語意、鍵盤調整及色彩對比。
  - 驗收：TalkBack 可讀出控制用途、目前顏色及選取狀態；所有主題在淺色與深色模式符合目標對比標準。

- [ ] **SDS-019 將所有使用者介面文字資源化**
  - 範圍：Compose、ViewModel、Repository 及 Exporter 中的標籤、訊息、錯誤與內容描述。
  - 驗收：使用者可見文字不再硬編碼於 Kotlin；頁數與動態內容使用格式化或複數資源；既有繁體中文介面無缺字串。

- [ ] **SDS-020 在 App 內加入隱私與授權入口**
  - 範圍：設定頁提供隱私、開放原始碼授權、儲存位置、資料刪除及 Google Play 服務說明。
  - 驗收：內容離線可讀；說明與 `docs/PRIVACY.md` 及實際權限一致；外部連結開啟失敗時有替代資訊。

## 工程品質

- [ ] **SDS-021 注入資料與匯出依賴**
  - 範圍：為 Repository、Exporter 與必要的平台操作建立可替換邊界，分離一次性事件與 UI 狀態。
  - 驗收：ViewModel 測試可模擬成功、部分成功與失敗，不需要真實 Room 或 MediaStore。

- [ ] **SDS-022 擴充自動化測試**
  - 範圍：頁數上限、刪除復原、排序持久化、匯入回滾、多 URI 分享、程序重建、大字體與深色主題。
  - 驗收：關鍵 P0 流程各有成功及失敗測試；CI 可執行單元測試、lint 與必要的儀器測試。

- [ ] **SDS-023 啟用 Room schema 與遷移測試**
  - 範圍：輸出 schema，為文件庫、匯出紀錄或 OCR 欄位建立明確 migration。
  - 驗收：既有版本 1 資料可升級且頁面檔案仍可開啟；migration test 納入 CI；禁止未提供遷移的正式資料庫升版。

- [ ] **SDS-024 建立大型文件與低資源壓力測試**
  - 範圍：50 頁、高解析圖片、低儲存空間、低記憶體、旋轉畫面及程序重建。
  - 驗收：完成測試裝置矩陣及結果紀錄；匯出不發生 OOM；失敗後沒有 pending MediaStore 項目或孤兒私有檔案。
