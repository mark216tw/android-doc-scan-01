# 版本變更紀錄

本文件記錄「簡單文件掃描」公開版本的重要變更。

## 1.0.0-prerelease - 2026-09-17

啟用 R8 並使用 Debug 金鑰簽署的測試發行版本。

### 新增與調整

- 設定改為具有返回導覽的完整頁面。
- 新增跟隨系統、淺色及深色三種顯示模式。
- 新增完整色相滑桿及自訂主題色盤。
- 狀態列與系統導覽列會配合顯示模式切換。
- 主畫面新增將 App 移至背景的按鈕。
- 設定頁新增版本與 Build 編碼資訊。
- 設定頁新增可捲動的完整功能說明頁。
- 建立新文件前新增確認步驟。
- JPEG 與 PDF 統一匯出至 `Download/簡單文件掃描`。
- 單份文件強制限制為最多 50 頁，主畫面會顯示目前頁數及剩餘容量。

## 0.1.0-debug - 2026-08-26

Debug 預覽版本，並非正式發行版本。

### 新增

- ML Kit 文件掃描與相簿匯入。
- 最多 50 頁的文件草稿。
- 頁面縮圖、左右排序與刪除功能。
- JPEG 與多頁 PDF 匯出。
- 最近匯出檔案的開啟及分享功能。
- Room 草稿保存。
- 六種主題色彩與深色模式。
- 系統導覽列深淺外觀同步。
- Adaptive Icon 與 Android 13 單色圖示。

### 注意事項

- APK 使用 Debug 金鑰簽署，僅供測試。
- 尚未完成所有實體裝置與大量頁面壓力測試。
- ML Kit 公開 API 目前無法由 App 指定預設手動拍攝模式。
